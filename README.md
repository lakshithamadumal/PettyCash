# PettyCash App

A simple, clean, mobile-friendly HTML-based Petty Cash management application designed to run inside an Android WebView.

## 🚀 Features
- Add Income & Expense
- LocalStorage data saving
- Beautiful UI built with TailwindCSS
- Custom Delete Confirmation Modal (No browser popups)
- Animated transitions and smooth UI
- Responsive layout

## 📁 Technologies Used
- **HTML5**
- **Tailwind CSS**
- **JavaScript (Vanilla)**
- **LocalStorage** for offline persistence
- **Android WebView** (Kotlin)

## 🧩 App Functions
### Add Transactions
- Income and Expense handled separately
- Form validation included

### Delete Transactions
- Custom modal confirmation (No default `confirm()`)

### Balance Calculation
- Auto-updates total balance
- Auto-updates income/expense totals

### Persistent Data
- Transactions saved using LocalStorage

## 📱 Android Integration
- Kotlin WebView setup
- Fullscreen immersive mode
- Custom status bar color
- Modern WindowInsets for system UI control
